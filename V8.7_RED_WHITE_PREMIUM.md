# SARKSH Foods V8.7 — Red + White Premium Production Theme

## Objective

V8.7 applies the approved customer-facing visual direction across the production website:

- deep red / maroon gradient background;
- white typography instead of gold UI text;
- white borders, dividers and premium call-to-action treatment;
- official SARKSH Foods logo preserved exactly;
- premium chilli powder photography retained;
- desktop, tablet and mobile responsive layouts preserved.

## Homepage

The homepage keeps the premium editorial split layout and uses exactly two hero calls to action:

1. **Shop Products**
2. **Business Orders**

Hero quotation:

> “A richer red. A bolder presence. Made to be remembered.”

## Palette

Primary gradient:

- `#390908`
- `#4B100D`
- `#5A1713`

Typography and interaction accent:

- `#FFFDFB`
- white with controlled opacity for secondary copy

No gold UI typography is used in the V8.7 customer-facing theme.

## Preserved production systems

V8.7 does not replace or modify the production backend architecture. It preserves:

- Apps Script backend version 8.4;
- private Google Sheets / Drive storage;
- customer account and saved-address flows;
- admin authentication;
- customer order history and reorder flows;
- V8.5 SEO, sitemap, canonical, crawler and IndexNow generation;
- `www.sarkshfoods.in` as the production canonical origin;
- approved 3D intro animation mechanics.
