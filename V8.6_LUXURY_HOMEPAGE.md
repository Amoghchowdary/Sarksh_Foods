# SARKSH Foods V8.6 — Luxury Homepage

## Scope
- New obsidian/charcoal/gold homepage hero based on the approved premium direction.
- Official SARKSH Foods master SVG added without recolouring or redrawing it.
- Hero uses the existing approved SARKSH Foods 1 kg chilli powder studio photograph.
- Primary CTAs: **Shop Products** and **Business Orders**.
- Header moved to a premium dark treatment with gold accenting.
- Responsive desktop, tablet and mobile layouts.
- Customer account, admin portal, Apps Script backend, Google Sheets/Drive architecture and V8.5 indexing stack remain intact.

## Critical rendering fix
V8.5 generated crawl-first SEO HTML inside `#app`, but the browser entrypoint only mounted React when `#app` was empty. That could leave the SEO shell visible instead of the interactive site. V8.6 preserves the crawl-first HTML for search engines, clears it when JavaScript starts in a real browser, and then mounts the React application.

## Production
Canonical production origin remains `https://www.sarkshfoods.in`.
Apps Script backend remains compatible with backend version 8.4.
