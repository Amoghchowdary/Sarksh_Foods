# SARKSH Foods V13

V13 keeps the finalized V11.2 design intact and concentrates changes in production security and discovery infrastructure.

Implemented:
- public/private repository separation
- Apps Script source removed from public Git package
- environment/credential ignore rules
- hardcoded production Apps Script endpoint removed from frontend and scripts
- GitHub Actions secret injection
- public-repository secret audit
- `www.sarkshfoods.in` canonical consolidation
- crawl-first semantic HTML
- Product, Brand, Organization, FAQ, Breadcrumb, ItemList and Service structured data
- page/product/image sitemap set and sitemap index
- robots rules for search and AI crawlers
- `llms.txt`, `llms-full.txt`, `ai.txt`
- public entity/product/brand JSON resources
- post-deploy crawl verification
- optional IndexNow submission
